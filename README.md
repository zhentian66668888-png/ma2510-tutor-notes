## Learning focus

- Model probability experiments and identify the relevant assumptions.
- Explain expectation, variance, covariance and conditional reasoning.
- Work through distributions, estimation and asymptotic arguments step by step.

## About this public edition

This repository collects the tutorial questions, worked solutions and supporting teaching notes. Inclusion of a course problem does not imply original authorship of every underlying question. Separate third-party tutorial and past-examination reference packs are kept separately.

File names are neutral. Identified personal names, contact details and PDF author metadata were removed from these copies. No student records or claims about student outcomes are included. The original private archive remains separate.
